# Security Policy

Thank you for helping keep Backwoods Dash Designer and the people who use it safe.

## Supported versions

Security fixes go into the **latest release** only. If you are on an older version, please update first.

## How to report a problem

**Please do not post security problems in a public issue.** Instead:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**. This sends a private report that only the maintainers can see.

If the button is not there, open a normal issue that says only "I would like to report a security problem" (no details) and we will arrange a private way to talk.

## What to include

- The program version and your operating system (Windows, macOS or Linux).
- What you did, step by step, and what happened.
- What you think could go wrong because of it.
- A small sample file if that is what triggers it. Please do not send files that contain private information.

## What to expect

- We will **reply within 7 days** to confirm we received your report.
- We will tell you when it is fixed and, if you like, **credit you** in the release notes. Tell us if you would rather stay anonymous.
- This is a small, independent project, so please be patient with us and give us a reasonable time to fix a problem before you share it publicly.

## What counts as a security problem here

Backwoods Dash Designer runs on your own computer. It has no accounts and no online features, and it does not send your designs anywhere. The things we care most about:

- **Opening files:** a crafted `.bwd`, STL, DXF, AI, EPS or image file that crashes the program or makes it do something it should not.
- **The build and release process:** anything in the GitHub workflows or release files that could let someone tamper with the downloads.
- **Anything that runs other programs or opens links** in a way a file or a name could take over.

Ordinary bugs, such as a wrong shape, a crash with no security impact, or a feature that does not work, are welcome as regular [issues](../../issues).
